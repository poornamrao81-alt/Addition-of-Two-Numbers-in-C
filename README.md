# Addition-of-Two-Numbers-in-C
A simple C program that takes two numbers as input, adds them, and displays their sum.
This program helps in understanding basic input/output operations, variables, and arithmetic operators in C.

## Concepts Used
- Variables
- Data Types
- `scanf()` and `printf()`
- Arithmetic operator (`+`)

## How It Works
1. Takes two numbers as input from the user.
2. Adds the two numbers.
3. Displays the sum.

## Sample Output
```text
Enter two numbers: 10 20
Sum = 30
```

## Learning Outcome
Practiced basic input/output operations and arithmetic calculations in C.
